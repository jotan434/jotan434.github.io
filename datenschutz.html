Was diese Website nicht macht

Diese Website verwendet keine Cookies, keine Analyse- oder Tracking-Tools, keine eingebetteten Karten oder Videos und lädt keine Schriftarten von fremden Servern. Einzige Ausnahme: der freiwillige Chat-Assistent (siehe unten).

Hosting

Die Website wird über GitHub Pages (GitHub, Inc., USA) bereitgestellt. Beim Aufruf verarbeitet GitHub technisch notwendige Daten wie Ihre IP-Adresse, um die Seite auszuliefern und die Sicherheit zu gewährleisten. Näheres: GitHub Privacy Statement.

Kontakt per E-Mail

Wenn Sie mir eine E-Mail schreiben, verwende ich Ihre Angaben nur, um Ihre Anfrage zu beantworten. Die Daten werden gelöscht, wenn sie dafür nicht mehr benötigt werden.

Chat-Assistent „Nova“ (KI)

Auf der Startseite können Sie einen KI-Chat nutzen. Er ist freiwillig: Solange Sie keine Nachricht senden, werden keine Chat-Daten übertragen. Wenn Sie eine Nachricht senden, geht sie an einen von mir betriebenen n8n-Server und wird dort von einem KI-Modell (Claude, Anthropic, USA) verarbeitet, das die Antwort erzeugt. Übermittelt werden Ihre Eingabe, eine zufällige Sitzungs-ID und die Adresse der Seite, auf der Sie sich befinden. Eine Übermittlung in die USA ist dabei möglich.

Bitte geben Sie im Chat keine personenbezogenen oder vertraulichen Daten ein. Für Anfragen nutzen Sie bitte die E-Mail-Adresse oben. Der Chat-Verlauf wird nur im Speicher Ihres Browser-Tabs (sessionStorage) gehalten und verschwindet, wenn Sie den Tab schließen. Es werden keine Cookies gesetzt.
